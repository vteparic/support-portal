## How I verified the page

## Remote change I received
I received the remote change after the README was updated on GitHub. I used `git pull` to bring the change from the remote repository to my local repository.

## Git workflow explanation
`git commit` only saves changes to my local Git repository. It does not automatically update GitHub. I had to use `git push` to send my committed changes to the remote repository on GitHub.
